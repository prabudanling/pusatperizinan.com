## 7. Dokumentasi API

Semua endpoint berada di bawah `src/app/api/`, tervalidasi Zod, dan tersambung ke Prisma.

### 7.1 `POST /api/leads` — Capture Lead
Form Hero & Final CTA. Normalisasi WA otomatis + estimasi nilai kontrak per paket.

```jsonc
// Request
{
  "name": "Andi Wijaya",
  "whatsapp": "0812-6999-9910",      // → dinormalisasi "6281269999910"
  "sector": "kuliner",
  "message": "Butuh NIB + Halal untuk kafe",
  "package": "bisnis"                // umkm | bisnis | enterprise
}
// Response 201
{ "id": "clx...", "estimatedValue": 3500000, "status": "new" }
```

### 7.2 `POST /api/chat` — RIZKI AI
Konsultan AI percakapan. Menyimpan riwayat per `sessionId`, **mendeteksi nomor WA** di teks → simpan lead, dan menerima `language` agar jawaban ditulis dalam bahasa pengunjung (dapat diganti di tengah sesi).

```jsonc
// Request
{ "sessionId": "abc123", "message": "How much for a PT?", "language": "en" }
// Response
{ "reply": "A PT (Perseroan Terbatas) typically costs between Rp 3.5–7 million…", "language": "en" }
```

### 7.3 `POST /api/license-checker` — Analisis Izin AI
Deskripsi usaha bebas → roadmap perizinan JSON terstruktur (NIB, UIK, Halal, BPOM, PBG, dst.) + estimasi biaya/waktu, dicatat ke tabel `LicenseCheck`.

```jsonc
// Request
{ "description": "Kedai kopi dengan 5 cabang di Bandung", "whatsapp": "0812xxxx" }
// Response
{ "roadmap": [{ "step": 1, "permit": "NIB", "cost": "Gratis", "duration": "1 hari" }, …] }
```

### 7.4 `GET /api/subscribe` / `POST /api/subscribe`
Kursus email 7 hari. `POST` melakukan **upsert anti-duplikat** via email; `GET` mengembalikan `count` (dengan baseline 1.200) untuk social proof live.

### 7.5 `GET /api/stats`
Counter social proof: jumlah klien, izin diproses, provinsi (38) & kab/kota (514) — data baseline di server, ter-cache memori.

## 9. Sistem Multibahasa (30 Bahasa)

### 9.1 Arsitektur

```
?lang=xx (URL)  ─┐
localStorage     ├─►  language-provider.tsx  ─►  <html lang dir>  +  t(key)
"pp-lang"        │      deteksi berlapis         sinkron otomatis     fallback:
navigator.langs  ─┘      (SSR-safe: id dulu,       (RTL otomatis       xx → id → key
                          queueMicrotask)          untuk 4 bahasa)
```

- **Kontrak tipe** `Translation` = **146 key** × 30 bahasa — divalidasi script terpusat: `30/30 bahasa, 146/146 key, 0 missing`
- **Fallback berlapis**: `t(key)` → bahasa aktif → `id` → key mentah — mustahil teks kosong
- **Token dinamis**: `{p}` (paket), `{n}` (angka), `{name}` (nama pengguna), `{year}` (hak cipta)
- **RTL penuh**: `dir="rtl"` disetel otomatis untuk **ar, fa, ur, he** — seluruh layout ter-mirror (logo kanan, form terbalik) tanpa CSS tambahan
- **Persistensi**: pilihan tersimpan di `localStorage("pp-lang")`, dipulihkan antar-navigasi

## 10. Arsitektur SEO Supremacy

## 17. FAQ Proyek

<details>
<summary><b>Mengapa satu halaman, bukan multi-rute?</b></summary>
Semua aset SEO terkonsentrasi pada satu URL berotoritas tinggi (anchor + JSON-LD + peta situs HTML), sementara fase 5-6 membuka rute programmatik saat domain live — strategi dominasi SERP dua gelombang.
</details>

<details>
<summary><b>Kenapa i18n kustom, bukan next-intl/routing per-lokale?</b></summary>
Situs satu halaman + 30 bahasa = 30× duplikasi rute tidak perlu. Provider dictionary + <code>?lang=</code> memberi pengalaman penuh (termasuk RTL) tanpa biaya rute, dan hreflang tetap terdeklarasi di metadata & sitemap. Rute dedikasi direncanakan Fase 6.
</details>

<details>
<summary><b>Apakah konten Indonesia-only jadi masalah untuk pengunjung asing?</b></summary>
Tidak — 17 layanan, 16 panduan, dan 13 artikel tetap berbahasa Indonesia sebagai aset SEO lokal, dan setiap section konten menyertakan <code>contentNote</code>: RIZKI AI menerjemahkan/menjelaskan konten tersebut dalam bahasa pengunjung secara interaktif.
</details>

<details>
<summary><b>Bagaimana keamanan API key AI?</b></summary>
<code>z-ai-web-dev-sdk</code> hanya dipanggil di API route (server). Browser tidak pernah melihat kredensial. Semua input divalidasi Zod sebelum menyentuh database.
</details>

<details>
<summary><b>Bagaimana menambah layanan/provinsi/artikel baru?</b></summary>
Semua deklaratif: tambah objek di <code>SERVICES</code>/<code>PROVINCES</code>/<code>BLOG_ARTICLES</code> — UI, peta situs, JSON-LD, dan cross-link mengalir otomatis.
</details>
